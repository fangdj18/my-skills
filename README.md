## 目录结构

```
my-skills/
├── README.md            # 本文件：技能总索引
├── find-skill/          # 技能查找器（可根据索引帮你定位技能）
│   └── SKILL.md
├── snapshots/           # 已安装技能的详情快照
└── TODO.md              # 待补充/待创建的技能需求
```

## 使用方式

1. **找技能**：对 AI 说"帮我找一个能做 XX 的技能"，或直接参考上面的索引表
2. **加技能**：每装一个新技能，在索引表加一行；详情丰富的可存一份快照到 `snapshots/`
3. **复用环境**：换电脑或新建会话时，把本仓库克隆下来即可找回所有技能说明
